# Stellar Burgers  — unit-тестирование

**Java · JUnit 4 · Mockito · JaCoCo**

Учебный проект Яндекс Практикума.

Проверяем, что конструктор бургера правильно считает цену, сохраняет порядок ингредиентов и формирует чек. В этом проекте бизнес-правила переведены в unit-сценарии с конкретными входными данными и ожидаемыми результатами.

## Подход к тестированию

- **Параметризация:** одна проверка расчета стоимости применяется к четырем наборам данных.
- **Проверка состояния:** добавление, удаление и перестановка ингредиентов проверяются по содержимому и порядку списка.
- **Изоляция зависимостей:** Mockito позволяет задавать цены и характеристики ингредиентов независимо от их реализации.
- **Проверка представления:** assertions сопоставляют ожидаемый и фактический текст чека.
- **Анализ покрытия:** JaCoCo показывает, какие участки модели затрагиваются проверками.

## Технологии

- Java;
- JUnit 4;
- Mockito;
- JaCoCo.

## Что проверяется

- Установка булочки и добавление ингредиентов.
- Удаление ингредиента и изменение порядка ингредиентов.
- Расчет стоимости с различными наборами данных, включая пустой список ингредиентов.
- Формирование чека с ингредиентами и без них.

Фокус проекта — класс `Burger`. Моки `Bun` и `Ingredient` помогают проверять его логику отдельно от зависимостей.

## Структура

```text
src/main/java/praktikum/        # модель бургера и консольный пример
src/test/java/                 # обычные и параметризованные проверки
pom.xml                        # зависимости и настройка JaCoCo
target/site/jacoco/             # отчет о покрытии
```

## Запуск

Скачайте исходники `main`, распакуйте их и откройте терминал в каталоге с `pom.xml`.

```bash
mvn verify
```

JaCoCo формирует отчет на фазе `verify`. После успешного выполнения откройте `target/site/jacoco/index.html` в браузере.[](https://github.com/Takiera/Diplom1/tree/main)
